# 📺 IPTV-com (Brasil)

O **IPTV-com** é um projeto de curadoria focado em organizar e manter listas de reprodução (M3U) de canais de televisão brasileiros que transmitem sinal aberto e gratuito pela internet.

---

## 🚀 Sobre o Projeto

Este projeto é uma ramificação estratégica focada na lusofonia (Brasil e países de língua portuguesa), utilizando como base a infraestrutura e dados globais do `iptv-org`. Nosso objetivo é oferecer uma lista limpa, funcional e organizada por categorias locais.

### 🎯 Diferenciais
* **Foco Regional:** Canais abertos, legislativos, universitários e locais do Brasil.
* **Organização PT-BR:** Grupos de canais nomeados em português (Notícias, Esportes, Cultura).
* **Verificação Ativa:** Links monitorados para evitar transmissões offline.

## 🛠️ Como Contribuir

Adoramos colaborações! Se você encontrou um canal que não está funcionando ou quer adicionar uma TV local da sua cidade:

1. Faça um **Fork** do projeto.
2. Crie uma branch para sua modificação (`git checkout -b feature/novo-canal`).
3. Adicione o link no arquivo correspondente dentro da pasta `/lists`.
4. Abra um **Pull Request**.

## ⚖️ Isenção de Responsabilidade (Disclaimer)

O **IPTV-com** é um agregador de links. 
* **Não hospedamos nenhum vídeo** em nossos servidores. 
* Todos os links apontam para transmissões oficiais e públicas disponibilizadas pelas próprias emissoras. 
* Se você é detentor de direitos autorais e deseja a remoção de algum link, por favor, abra uma *Issue*.
